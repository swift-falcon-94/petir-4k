Petir 4K: a 0x88 alpha-beta chess engine in 4 KB of Python. Iterative deepening to a fixed node budget, quiescence, tapered piece-square tables, a transposition table and killer moves. It plays the gauntlet through the trial env: deterministic, no clock, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
